01

첫 자동화 만들기

누군가 채팅에 “안녕”이라고 쓰면 봇이 인사하도록 만들어 봐요.

  1. 대시보드에서 서버를 선택하고 프로젝트를 열어요.
  2. 이벤트에서 새 메시지가 올라오면 블록을 놓아요.
  3. 조건문에서 만약 블록을 이벤트 아래에 연결해요.
  4. 조건에서 메시지에 단어가 포함되면 블록을 만약의 조건 칸에 연결하고 “안녕”을 입력해요.
  5. 동작에서 메시지 보내기 블록을 만약 안쪽에 연결하고 채널과 답장 문구를 정해요.
  6. 저장한 다음 실행 활성화를 눌러요.
완성된 흐름
새 메시지가 올라오면
　└ 만약 메시지에 “안녕”이 포함되면
　　　└ #일반 채널에 “안녕하세요!” 보내기
02

슬래쉬 명령어 만들기

사용자가 직접 명령어를 실행했을 때 시작하는 자동화예요.

  1. 이벤트에서 슬래쉬 명령어가 실행되면 블록을 선택해요.
  2. 명령어 이름은 영문 소문자와 숫자, 밑줄로 입력해요. 예: hello.
  3. 설명과 선택 입력 옵션을 정해요.
  4. 동작에서 슬래쉬 명령어에 응답하기를 연결해 응답 문구와 공개 범위를 설정해요.
  5. 저장하고 실행을 활성화해요. 봇이 서버 명령어 목록을 동기화한 뒤 사용할 수 있어요.
03

웹훅으로 메시지 보내기

봇의 기본 이름 대신 지정한 표시 이름과 프로필 이미지로 메시지를 보낼 수 있어요.

  1. 동작에서 웹훅으로 메시지 보내기 블록을 선택해요.
  2. 전송할 채널과 웹훅 이름을 설정해요.
  3. 표시 이름, 프로필 이미지 URL, 메시지 내용을 입력해요.
  4. 필요하면 임베드 제목·설명·색상도 추가해요.
  5. 봇이 프로젝트용 웹훅을 준비해 메시지를 전송해요.

웹훅 토큰은 프로젝트 화면에 표시되거나 저장되지 않아요.

04

저장과 테스트

  1. 프로젝트당 최대 50개 블록까지 사용할 수 있어요.
  2. 저장 버튼을 눌러 변경 사항을 저장해요.
  3. 실행 기록에서 성공·실패 여부를 확인해요.
  4. 원하는 대로 작동하지 않으면 이벤트, 조건, 채널과 봇 권한을 확인해요.
