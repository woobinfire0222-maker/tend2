이벤트에서 시작

새 메시지, 멤버 입장과 퇴장처럼 Discord에서 발생한 이벤트를 자동화의 시작점으로 사용해요.

◇

조건으로 분기

메시지에 특정 단어가 있는지, 사용자가 특정 역할을 가지고 있는지 확인해요.

▤

동작을 연결

메시지·임베드 전송, 답글, 역할 지급과 회수, 경고 등 지원되는 동작을 연결해요.

⌁

메시지 세부 설정

채널, 본문, 멘션 범위, 답글 대상, 자동 삭제와 임베드 표시를 설정할 수 있어요.

≋

변수 활용

변수에 값을 저장하고 변경해 자동화 안에서 다시 사용할 수 있어요.

▣

프로젝트 관리

서버별로 프로젝트를 저장하고 실행 여부를 관리해요. 모든 변경 사항은 계정과 서버 권한으로 보호돼요.
